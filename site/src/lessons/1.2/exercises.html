What the tests check that you might not

These are not there to be awkward. Each one is a property that must hold, and each one has caught somebody.

  • Distance is symmetric. distance(a, b) must equal distance(b, a). If you subtract in one order and forget that squaring removes the sign, you will not notice until it matters.
  • Exercise 2 must agree with exercise 1. Two implementations of the same idea, checked against each other on the same input. If they disagree, one of them is wrong and you get to find out which.
  • Scaling must not change an angle. angle_between([2,2], [10,10]) is zero. If your answer moves when a vector gets longer, you have not divided out the magnitudes.
  • The projection must point along b. Checked with a cross product, which is zero exactly when two vectors are parallel.
  • project + reject must reconstruct a. The two pieces are a decomposition, so they must add back to what you started with. This is checked on random vectors in six dimensions, where you cannot eyeball it.
  • The rejection must be perpendicular to b. Not approximately, by argument — measured, with a dot product.

Then run the demo

Once all seven pass, run the file directly. It builds the disagreement case from the lesson so you can watch it rather than take my word for it.

The stretch, if you want it

stretch.py is optional and not scored. Two tasks: build the full n×n distance matrix with no loop anywhere, and check the claim that normalised vectors rank the same by distance and by cosine.

The first one is your introduction to broadcasting, which is the entire subject of lesson 1.3. The file walks you into it rather than assuming it.

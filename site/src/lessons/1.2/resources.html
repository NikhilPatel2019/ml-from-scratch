The second half, on duality, is genuinely hard and not needed yet — losing the thread there is expected, and it returns in phase 3.

Reference, when you hit it

  • numpy.clip — short. Read it when you reach exercise 3, not before.
  • numpy.linalg.norm — what you would reach for in real code instead of writing magnitude yourself. Read the axis parameter now: it is how the stretch file avoids a loop, and it is most of lesson 1.3.
  • numpy.isclose — the standard answer to "never compare floats with ==". Note it takes both an absolute and a relative tolerance, and why you would want each.

Later, not now

  • What Every Computer Scientist Should Know About Floating-Point Arithmetic — do not read this today. Bookmark it. When floating point eventually costs you a day, the answer is in here.
  • Anything on eigenvalues, SVD or PCA. Projection is the seed of all three and you have just planted it. Phase 2.

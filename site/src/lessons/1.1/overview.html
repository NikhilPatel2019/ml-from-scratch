Machine learning begins with one move: turning things into lists of numbers so that "similar" becomes arithmetic. This lesson covers that move, and the single operation everything else in the field is built from.

01

Represent anything as a vector

Why a list of numbers can stand in for a house, a customer or a word, and what "4096-dimensional" actually means.

02

Compute and read a dot product

Implement it by hand, then vectorised — and explain what a result of zero tells you about two things.

03

Measure similarity properly

Find the flaw in the raw dot product, fix it with cosine similarity, and understand why the fix works.

04

Build a working search engine

Rank a small library by meaning — the same mechanism behind semantic search and every RAG system.

05

Think in arrays, not loops

The mental shift NumPy demands, and the memory-layout reason it is roughly 200× faster.

Before you start

PrerequisitesNone. This is the first lesson. You can already program in some language; no maths is assumed.
You will needPython 3.10+, the repository cloned, and pip install -e ".[dev]" run once.
ExercisesSeven, plus one optional stretch. The tests check how you solved it, not only the answer.
Maths introducedVectors, the dot product, magnitude, and cosine. All built from arithmetic — no calculus, no notation you have not met.

You are done when

Not when the tests pass — when you can answer these without looking anything up:

  • What does a dot product of zero tell you about two vectors?
  • Why divide by the magnitudes to get cosine similarity — what does it fix?
  • Why is a NumPy operation so much faster than the equivalent Python loop?
  • Where does a neuron use the function you wrote today?
One rule for this whole curriculum

Nobody hands you the answer — not this page, and not whatever model you ask for help. Recognising correct code is a different skill from producing it, and only one of them transfers. Ask for a smaller sub-problem when you are stuck. Ask why your working code is bad. Do not ask for the solution.

# Phase 0 — Foundations

*the maths, built in code*

All of machine learning stands on four ideas: vectors, matrix multiplication, the derivative, and probability. Learn these properly and the rest of the field is recombination. We learn them by writing them, not by reading proofs.

**Milestone:** Minimise a function you have never seen before, from scratch, and explain every line.

---

## Lessons

| | Lesson | What it covers | |
|---:|---|---|---|

| `0.5` | Systems, inverses, and rank | Solving Ax = b, the cases where you cannot, and what 'singular' actually means. | planned |
| `0.6` | Functions and slopes | The derivative discovered numerically, in code, before a single symbol of calculus notation. | planned |
| `0.7` | Derivative rules | Power, product and quotient rules — and the handful of derivatives you will actually reuse forever. | planned |
| `0.8` | The chain rule | The most important single fact in deep learning. Backpropagation is the chain rule and nothing more. | planned |

| `0.11` | Probability I | Random variables, distributions, expectation and variance — the language uncertainty is written in. | planned |
| `0.12` | Probability II | Bayes' theorem, likelihood, and the derivation of where loss functions actually come from. | planned |
| `0.13` | The statistics you need | The normal distribution, sampling, correlation, and the traps that catch practitioners. | planned |

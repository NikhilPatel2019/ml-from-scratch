# Phase 2 — Classical Machine Learning

*where every core concept is easiest to see*

Most industry ML is still this. It is also where loss, overfitting, evaluation and regularisation are visible in two dimensions, before deep learning hides them behind a billion parameters.

**Milestone:** Take a raw, messy CSV to a validated and honestly-evaluated model, and defend every choice you made.

---

## Lessons

| | Lesson | What it covers | |
|---:|---|---|---|
| `2.1` | What 'learning' actually is | The universal recipe underneath every model in this repository: data, model, loss, optimiser. | planned |
| `2.2` | Linear regression from scratch | Both routes: the closed-form solution, and gradient descent. Then why anyone bothers with the second. | planned |
| `2.3` | Making training work | Feature scaling, learning rates, and how to debug a model that will not converge. | planned |
| `2.4` | Logistic regression | The sigmoid, decision boundaries, and cross-entropy loss — classification from first principles. | planned |
| `2.5` | Overfitting and the bias-variance tradeoff | Train/validation/test, cross-validation, and why your model looked brilliant right up until it shipped. | planned |
| `2.6` | Regularisation | L1 and L2, and a real intuition for why penalising large weights makes a model generalise. | planned |
| `2.7` | Evaluation | Accuracy is a trap. Precision, recall, F1, ROC-AUC and confusion matrices, and when each one lies. | planned |
| `2.8` | scikit-learn | Now that you have built it by hand, learn the tool everyone actually uses. | planned |
| `2.9` | Trees, forests, and gradient boosting | Decision trees to random forests to XGBoost and LightGBM — still the champions on tabular data. | planned |
| `2.10` | Feature engineering | Encoding, missing data, and data leakage — the number one bug in real-world machine learning. | planned |
| `2.11` | Clustering | k-means, hierarchical clustering and DBSCAN: finding structure with no labels at all. | planned |
| `2.12` | PCA and dimensionality reduction | Where the linear algebra from Phase 1 pays off spectacularly, and eigenvectors finally earn their keep. | planned |
| `2.13` | Capstone: end to end | A real, messy dataset from raw file to evaluated model, with every decision written down and justified. | planned |

# Phase 4 — Transformers and LLMs

*from attention to a working GPT*

Attention derived rather than memorised, a byte-pair tokeniser you implement yourself, and a small GPT written line by line and trained on a corpus you choose.

**Milestone:** A working GPT you wrote yourself, generating text.

---

## Lessons

| | Lesson | What it covers | |
|---:|---|---|---|
| `4.1` | Attention from first principles | Derived, not memorised. Queries, keys and values as a solution to a problem you will feel first. | planned |
| `4.2` | Self-attention and multi-head attention | Why several attention heads beat one, and how position gets encoded into an order-blind architecture. | planned |
| `4.3` | The transformer block | Residual connections, normalisation, feed-forward layers, and encoder versus decoder. | planned |
| `4.4` | Tokenisation | Implement byte-pair encoding, then discover why so many odd model behaviours start right here. | planned |
| `4.5` | Build GPT from scratch | The full architecture, written line by line and trained on a small corpus until it generates text. | planned |
| `4.6` | Pretraining and scaling laws | What 'emergence' does and does not mean, and how compute, data and parameters trade off. | planned |
| `4.7` | Fine-tuning | Full fine-tuning, LoRA and PEFT, and instruction tuning — adapting a model you did not train. | planned |
| `4.8` | Alignment | RLHF and DPO: how a text predictor becomes something you can hold a conversation with. | planned |
| `4.9` | Inference | Sampling, temperature, top-k and top-p, the KV cache, and quantisation. | planned |
| `4.10` | Embeddings, vector search and RAG | Retrieval done properly rather than cargo-culted — and this is where lesson 1.1 comes back around. | planned |
| `4.11` | Evaluations | The most underrated skill in applied AI, and the one that separates demos from products. | planned |
| `4.12` | Agents and tool use | The current frontier: planning, tool calling, and where it genuinely does not work yet. | planned |

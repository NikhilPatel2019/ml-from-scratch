# Phase 4 — Production and Specialisation

*models that survive contact with users*

A trained model is roughly ten percent of a machine learning product. This phase covers the other ninety, then you choose a direction to go deep in.

**Milestone:** A model you built, deployed, monitored, and can reason about when it degrades.

## Lessons

|---:|---|---|---|
| `4.1` | Serving and inference in production | Latency, throughput, cost, batching and the tradeoffs nobody mentions in tutorials. | planned |
| `4.2` | Monitoring and drift | Models decay silently. Detecting it, measuring it, and deciding when to retrain. | planned |
| `4.3` | Reproducibility and experiment tracking | Versioning data, code and weights so that a result from six months ago can be rebuilt. | planned |
